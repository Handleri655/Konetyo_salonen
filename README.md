# Konetyö M. Salonen Oy — verkkosivut

Sivusto GitHub Pagesissa: [https://handleri655.github.io/Konetyo_salonen](https://handleri655.github.io/Konetyo_salonen)

## Paikallinen esikatselu

```bash
npm install
npm run dev
```

Avaa [http://localhost:4321/Konetyo_salonen](http://localhost:4321/Konetyo_salonen) (polussa on repon nimi, sama kuin GitHub Pagesissa).

## Julkaisu

Push `main`-haaraan. GitHub Actions rakentaa sivuston ja julkaisee sen Pagesiin.

Repo → Settings → Pages → Source: **GitHub Actions**, jos sivusto ei näy ensimmäisen pushin jälkeen.

Lomakkeen ensimmäinen viesti pitää vahvistaa Formsubmit-sähköpostissa (`matti@konetyosalonen.fi`).

## Sisällön päivitys

Yrityksen tiedot, palvelut ja ajankohtaiset ilmoitukset: `src/data/site.ts`.
